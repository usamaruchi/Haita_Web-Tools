# Haita 工具收藏

個人使用的繁體中文工具收藏頁，預載 100 項工具與 21 個分類。

直接開啟 `dist/index.html` 即可使用，不需安裝依賴或建置。亦可將 `dist` 發布到靜態網站主機。

- 搜尋名稱、功能、網址、標籤與分類；支援分類、最愛篩選與排序。
- 新增、編輯、刪除工具，設定最愛。
- JSON 匯入與匯出；匯入會取代現有清單，操作前會要求確認。
- 變更儲存在目前瀏覽器的 localStorage，不會跨裝置同步。換網址、瀏覽器或清除網站資料前，請先匯出備份。私密瀏覽關閉後可能不保留資料。
- 初始工具位於 `dist/data.js`；新加入的預設工具會自動合併到既有收藏，保留最愛、自訂內容與已刪除的舊項目。新版備份也會記錄已接收的預設項目，避免刪除後重新出現。
- 支援舊版陣列與 v1 備份，匯出使用 v2 格式。舊版備份匯入時會補上新加入的預設工具。
- 截圖中的兩筆 PKstep 因原網址被截短，暫合併為一個已核對的字型資源入口。
- Google 字型無法連線時，自動使用系統字型。頁面其餘功能不依賴外部服務。

本機程式檢查：`node --check dist/app.js`、`node --check dist/data.js`。
